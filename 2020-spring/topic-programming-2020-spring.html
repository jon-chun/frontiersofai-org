Programming Paradigms – Language and Thought
M Class:              Evolution and Paradigms in Programming
W Lab:                Parsing Natural and Artificial Grammars
F Discussion:      Philosophy of Language

This week we study programming computation from the perspective of languages both artificial (e.g. Python) and natural (e.g. English). In addition, we’ll add the Pandas library to our Python toolbox that will help us clean up messy datasets for our next Mini-Project: Data Wrangling.

We’ll use code exercises to revisit a few key topics like encryption, password cracking, programming paradigms (esp OOPs) and recursion. New topics include natural language processing and compiler design to compare how computers parse English text vs Python code. Finally, we’ll touch upon Software Development Life Cycle (SDLC) as well as the software architectural shift from monolithic applications towards micro-services via RESTful APIs.

This week will also consider the unique position language occupies in the evolution of human cognition. We’ll consider how language in general, and stories in particular, may act as a type of Operating System and organizing principle for the the hardware (wetware) of our biological brain.

To accommodate the diversity of programming experiences in our class we have two parallel sets of readings on Monday.  Students only need to do one of these two options.  For those new to programming or who haven’t taken our ‘AI for the Humanities’ course we have curated a few of the best intro to Python courses for you.  For more experienced programmers, we have a different but hopefully equally interesting Python learning assignment focused on getting you beyond the conceptional ‘beginner’/’hacker’ hump.
