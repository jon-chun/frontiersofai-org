This week we study how Computer Science represents and implements one familiar aspect of cognition (algorithmic thinking) in code.  We’ll study this with examples of specific algorithms (e.g. sort) and a general pattern of computation (e.g. recursion).  More generally, we’ll introduce the Object-Orientated Programming (OOP) paradigm as one framework for modeling ‘reality’ in software by closely coordinating the intimate relationship between data structures and algorithms. We’ll also explore measures of algorithmic space-time complexity through BigO notation.

We close the week with a review of the intellectual history of formalized systems of thought from Philosophy to Logic to Maths to Computer Science. Also, we’ll read about the growing awareness and study of the relationships between matter, cognition and consciousness applied to both human and artificial intelligence.

Monday Introduction:

Python is a multi-paradigm language and we generally stick to a Procedural style of programming for simplicity. However, Python itself and the most popular library APIs are largely implemented in an Object-Oriented Programming style so one needs to become familiar with this mode of structuring code. In addition, we’ll review together in class one of the most concise crash courses on Python out there (email or bring your questions to Monday’s class).

  • Part 1 & 2: Object-Oriented Programming in Python, DataCamp.com
  • Chp2 A Crash Course in Python by Joel Grus (available at SafariBooksOnline via LBIS.kenyon.edu)

Wednesday Lab:

We review data structures from last week and introduce algorithms this week. In addition, we cover a few major related topics like recursion, BigO notation (to quantify algo complexity) as well as explain the popular concept of Computer Science = Data Structures + Algorithms. Finally, we look at the human brain from a computational perspective to appreciate a potentially very different implementation of computation in meatware.

  • Data Structures: Crash Course in CS #14 (10:06) PBS, May 2017
  • Khan Academy, A Guessing Game (Binary Search Algorithm)
  • Khan Academy, Intro to Algorithms (5:27)
  • Big-O Notation in 5 Minutes (5:12) Michael Sambol, Jan 2017
  • Python: Recursion Explained, Joe James (8:44) Nov 2017
  • Object-Orientated Programming in 7 Minutes, Programming with Mosh (7:33) Mar 2018
  • Theory of Mind Through the Lens of Algorithms, Andrea Diaconescu, TEDxZurich (12:18)

Thursday 11:00 am-12:15: Python for non-Programmers

  • Python for Developers
  • Grus Review

This is a 75min introduction to Python from the simplest elements. Bring your laptop and we’ll work through basic programming concepts like variables, loops and input/output. We’ll also go through the most common basic Python commands with minimal programming examples: manipulating variables, searching a list of names and reading/writing files. If time permits, we’ll explain basic features of Jupyter notebooks, the Python ecosystem and stepping through your code to help visualize exactly what is happening with each statement.

Friday Discussion:

Now that we understand a bit of both how artificial and human cognition are implemented, we’ll review the intellectual history of computation. We’ll also address a natural follow-up question: “What is consciousness?”  We do this from a variety of perspectives including from physicist Max Tegmark, philosopher Daniel Dennett and neuroscientist Giulio Tononi. We have more shorter readings to give you a diversity of interpretations on this subject across different fields.
