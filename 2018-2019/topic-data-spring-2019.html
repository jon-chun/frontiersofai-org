Wednesday Intro/Lab: (Read/Do before Wed class)

For those without prior programming experience, just try to read through and get a general understanding of how Python classifies, declares and represents different data types.  You don’t have to memorize details beyond the main data taxonomy illustration and what each type means at this point.  Similarly, the Monty Hall Problem will be explained in class, but consider the problem in advance and think how the data revealed explains the answer and why your intuition can be misleading.

  • (main) Python Data Structures Tutorial, Sejal Jaiswal, DataCamp.com, Dec 2017 (Alternate for those with previous Python programming experience – Pandas Tutorial: DataFrames in Python, DataCamp.com, Feb 2018)
  • Software Carpentry: Python Lists
  • The Monty Hall Problem, Victor Powell
