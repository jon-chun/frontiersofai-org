Until now, we’ve largely been dealing directly with numerical data. While we can

Today we want to quickly cover the following fundamentals of Natural Language Processing including:

  • Web Scraping
  • Python/Pandas built-in functionality to directly manipulate textual data types/abstractions
  • Textual Data Wrangling (e.g. cleaning, normalizing, etc)
  • NLP pre/processing (e.g. steming/lemmas, POS, etc)
  • Word Vectorization
  • Topic Modeling
  • Sentiment Analysis

In our limited time, the goal is to give a quick introduction and code walk-thru via various Google Colab notebooks. We want to give an overview of how these different NLP tasks/techniques work together and individually as part of the iterative investigative process of data science using text.
