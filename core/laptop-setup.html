Laptop Setup

Home » Core » Laptop Setup
Created: 2019-01-13 • Modified: 2019-01-16

Here is a list of local client software and remote cloud applications/resources that we will potentially explore in our class.  

It is recommended that students their own laptops to mirror the course lab laptops so they will have a fully configured and working personal laptop by the end of our course.  Aside from laptops, all resources free and selected and configured to reduce potential software conflicts and minimize the need for technical support.

Requirements

  • Laptop running relatively recent MacOS or Windows 10
  • Reference lab laptop is a MacBook Pro 13′ mid-2012 2.5GHz i5 4GB DDR3 500GB HDD running macOS Sierra 10.12.5
  • Current Chrome or Firefox browser

Install Local Software

  • Anaconda Python 3.7 Distribution
  • Github Desktop and CLI (just Git)
  • Visual Studio Code
  • OpenRefine
  • RapidMiner (free version)
  • Tableau Public (free version)
  • R Programming Language
  • RStudio Desktop (free version)

Cloud Services / Accounts

  • Google
  • Kaggle
  • Github
  • Tableau Public
  • DataCamp

Recommended

  • Both
    • Docker (Required Win 10 Pro and up)
  • Mac
    • Homebrew Package Installer
    • iTerm2 Terminal Application
    • Brew install command line utilities, ‘wget’, ‘jq’, and ‘httpie’
    • Xcode
  • Windows 10
    • Ubuntu Linux Subsystem
