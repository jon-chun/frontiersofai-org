Word Embeddings:

These must be done locally due to the large size of the language models. Typically:

  1. conda create -n py37nlp python=3.7
  2. source activate py37nlp
  3. conda install -c conda-forge spacy gensim
  4. python -m spacy download en_core_web_sm
  5. python -m spacy download es_core_news_sm
  6. jupyter notebook
  7. load and run these notebooks locally
