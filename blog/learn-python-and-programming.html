Learn Python and Programming

Home » Blog » Learn Python and Programming
Posted by jonchunMay 1, 2019

As our semester wraps up and summer approaches I was asked for recommendations to study Python/programming over the summer.

Python has become the de facto lingua franca of computational approaches across many fields including CS Education, Data Analytics, Machine Learning, Deep Learning, Robotics, DevOps, etc. It’s not my favorite language, but it is incredibly practical, efficient and powerful. More than any other language I can think of, Python justly earns the moniker of the ‘second best language for everything’. Furthermore, Python has tremendous momentum and by various metrics has surpassed R in data science (2017) and JavaScript in questions on StackOverflow (2019).

For all these reasons and more we rely upon Python in our DH courses and encourage our students to continue learning Python more than can be covered in an introductory course by whatever means suits their learning style and schedules.

For those who have free time this summer, here are a few resources that do a great job teaching the fundamentals of programming and Python for various levels (check at the official Python website and here and here for more detailed lists of suggestions on getting started). Happy coding!

Absolute Beginner:

  • Introducing Python, 2nd ed, Bill Lubanovic, O’Reilly, 2019 (pre-print looks great)
  • DataCamp.com Learn Python courses: These courses break learning Python down into small, standalone and easily digestible modules. They have arguably the best integration of material with writing/correcting live code for great reinforcement learning.
  • LearnPython.org is a simpler, cut-down version of DataCamp but free.
  • Google’s Python Class for those who like to step through with video instruction (albeit a bit dated at 2010)

Intermediate:

  • How to Think Like a Computer Scientists, 2nd ed, Allen Downey, O’Reilly, 2015
  • Composing Programs (Free online textbook inspired by SICP allows you to step through code embedded in web pages)
  • (Formal) Harvard/Yale CS50: The 2nd most popular undergrad course at Harvard that is well designed, engaging and surprising through.
  • Think Python: How to Think Like A Computer Scientist, Allen Downey
  • How to Think Like a Computer Scientist, RSI Despite the plain user interface, this is one of the highly recommend free online tutorials due to embedded interactive code cells (Used in Introductory Programming at Kenyon)

Advanced:

  • Python Software Foundation, read the official documentation on the language, standard library APIs and guides. (Python fundamentals start with RTFM)
  • The Hitchhikers Guide to Python, Kenneth Reitz and Tanya Schlusser (Python ecosystem reference for real-world software development)
  • Fluent Python: Clear, Concise and Effective Programming, Luciano Romahlo, O’Reilly 2015 (Elegant and efficient Python style/idoms)
  • Effective Python: 59 Specific Ways to Write Better Python, Brett Slatkin, Addison-Wesley Professional, 2015 (Elegant and efficient Python style/idioms)
  • Algorithms implemented in Python (Algo reference)
  • Github Awesome Python (Python ecosystem reference)
  • Github Python Software Patterns (Python patterns for the Software Architect)
  • Read Great Code written in Python (e.g. Flask) (Study real-world Python code bases and software architectures from the masters)
  • Finally: If the above doesn’t speak to you or is all old hat for you, come see me. There are many more advanced software visualization, modeling, mathematics and machine learning/AI resources I can match up with your background, interests and thoughts around your project for our course. – Prof Chun
