Designing Programming Languages

Home » Blog » Designing Programming Languages
Posted by jonchunJanuary 23, 2019

“A programming language cannot be derived from first principles alone. Language design is applied psychology—the computer program is the ultimate human-computer interface. Sometimes you have to try a design out and see how people interact with it and iterate based on that real-world feedback.”

– Jeff Bezanson, Stefan Karpinski, and Viral B. Shah – James H. Wilkinson Prize for Numerical Software

Apropos of our week studying programming languages and computational thought, the quote above beautifully captures the true metric of successful programming language design. By hewing true to the simple mathematical roots of computing, languages like Julia and Haskell minimize the annoying intellectual cruft that interfere with the efficient and natural expression of computation.

Every programming language and software framework comes with differing degrees of annoying particulars. This additional mental overhead becomes ever more intolerable the more one realize how unnecessary most such obstacles are in the light of well-designed languages like Julia.

Congratulations to the Julia team and thank you for moving the needle for humanity.
