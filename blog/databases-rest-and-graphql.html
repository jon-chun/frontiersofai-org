After the theory behind database technologies in last class we made these concepts more concrete by exploring some more practical applications today.

It's amazing how simple it is to setup a REST API with Flask:

  • Database, wikipedia.org
  • Creating Web APIs with Python and Flask, Patrick Smyth, ProgrammingHistorian.org 2 Apr 2018
  • How to Build RESTful APIs with Python and Flask, Onwuka Gideon, CodeMentor.io 5 Jan 2018
  • Build a RESTful API with Flask - The TDD Way, Jee Gikera, Scotch.io 3 May 2017
  • Flask REST API Server with Flask + SQLAlchemy + Marshmallow, Brad Traversy, Github 7 Jan 2019
  • A Gentle Introduction to GraphQL with Elixir and Phoenix, Brandon Richey, (Elixir v.1.6.5 and Phoenix v.1.3.2)

Database technologies are core the entire narrative of our infrastructure and form the foundations of

  • Marshmallow, Object serialization and deserialization, lightweight and fluffy
  • PostgREST
  • DBeaver, Multi-platform database tool
